# Student Management System Laravel

A complete Student Management System developed using Laravel.

## Features

✅ User Authentication (Login/Register)
✅ Dashboard
✅ Student Management CRUD
✅ Course Management CRUD
✅ Student-Course Relationship
✅ REST API
✅ Sanctum Authentication
✅ API Token Security
✅ API Documentation
✅ Postman Testing

## Technology Used

- Laravel
- PHP
- MySQL
- Bootstrap
- Laravel Sanctum
- Postman

## Modules

### Authentication
- Register
- Login
- Logout

### Student Management
- Add Student
- View Students
- Update Student
- Delete Student

### Course Management
- Add Course
- View Course
- Update Course
- Delete Course

### REST API

API Endpoints:

POST /api/register

POST /api/login

GET /api/students

POST /api/students

PUT /api/students/{id}

DELETE /api/students/{id}
