# Lost & Found Management System

## Project Overview

Lost & Found Management System is a web-based application developed using Laravel.

This system helps students/users report lost and found items and allows administrators to manage, verify, and approve reported items.
## Objectives

- Provide an online platform for reporting lost and found items
- Reduce manual searching process
- Allow administrators to verify reported items
- Maintain organized records of users and items


## Features

### User Module

- User Registration & Login
- Report Lost Item
- Report Found Item
- View My Items
- Edit/Delete Own Items
- Track Item Status


### Admin Module

- Admin Dashboard
- Manage Categories
- Approve Items
- Reject Items
- Delete Items
- Generate Certificates
